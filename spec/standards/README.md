# International standards

This area is reserved for reusable semantics defined by international or cross-jurisdiction standards rather than one country.

Potential future modules include:

- ISO 3166 country and subdivision identifiers;
- ISO 4217 currency identifiers;
- BCP 47 language tags;
- E.164 telephone representation;
- IBAN;
- BIC/SWIFT;
- other stable standards with a justified reusable contract.

A standard is added only when Core can define a coherent, versioned contract and conformance vectors. This directory is not a placeholder for speculative code generation or a dump of external datasets.
